# BIC Seguros — Assinaturas de email

Propostas de assinatura de email da BIC Seguros.

## Como ver

Abra [`assinaturas/index.html`](assinaturas/index.html) no navegador (ou o [`index.html`](index.html) na raiz, que redirecciona para a lista).

Cada proposta pode ser aberta individualmente. Depois, copie apenas a tabela da assinatura para o Outlook, Gmail ou outro cliente de email.
